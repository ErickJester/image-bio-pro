Tres principios

Lo que explica todo lo que vamos a ver

1

No suponer

Si falta un dato, el sitio no lo inventa: lo dice en pantalla. Prefiere un aviso claro a un número dudoso.

2

Separar

Lo que decide la red y lo que mide el código van aparte. Cada medida se verifica sin abrir la red.

3

Reproducir

El entrenamiento está en un cuaderno de Colab que cualquiera puede abrir. El modelo guarda la configuración con la que se entrenó.
