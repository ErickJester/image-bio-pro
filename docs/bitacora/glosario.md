# Glosario

Términos nuevos del proyecto, definidos con mis palabras. En orden alfabético.

| Término | Qué es | Dónde lo vi |
|---|---|---|
| `.gitignore` | Lista de archivos y carpetas que Git no debe subir al repositorio | Módulo 1 |
| Entorno virtual (`venv`) | Carpeta del proyecto con su propio Python y sus propias librerías, aislada del resto de la computadora | Módulo 1 |
| Política de ejecución | Configuración de seguridad de PowerShell que decide qué scripts `.ps1` se pueden ejecutar | Módulo 1 |
| `pip` | Programa que instala librerías de Python dentro del entorno activo | Módulo 1 |
| `py` | Lanzador de Python en Windows que permite elegir la versión, por ejemplo `py -3.12` | Módulo 1 |
| `requirements.txt` | Lista de librerías del proyecto para instalarlas igual en cualquier computadora | Módulo 1 |
| Terminal | Ventana para dar órdenes escritas a la computadora; en Windows es PowerShell | Módulo 1 |
